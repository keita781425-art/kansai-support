# sns/

Instagramの自動投稿（kansai-line-bot）で使う画像の置き場。公開URLは https://kansai-shinseikatu.com/sns/<投稿日-名前>/<番号>.jpg
- Instagramの仕様でJPEGだけ。**1080×1350（4:5）**（11/4〜。プロフィール一覧は3:4で真ん中が切り取られるので、表紙の文字は真ん中に寄せる）。1枚の投稿の中は全部同じサイズにする。
- 投稿管理（Notion）の「画像URL一覧」に、1行に1つずつ順番どおりに入れる。
- 投稿が終わっても消さない（Instagram側には残るが、念のため置いておく）。
